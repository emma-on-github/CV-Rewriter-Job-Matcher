# Run and deploy your AI Studio app

This contains everything you need to run your app locally.

View your app in AI Studio: [https://ai.studio/apps/bd79d402-48d6-497f-936e-ae88e3375b19](https://www.google.com/url?sa=E&q=https%3A%2F%2Fais-pre-hop5uqynkdxncrboxpp7wo-404110964701.europe-west2.run.app)

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
